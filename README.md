# LangChain Learn Track

This repository is dedicated to learning and experimenting with LangChain concepts, primarily through interactive Jupyter Notebooks and Python scripts.

**Live Demo:**  
Try the Streamlit app: [LangGraph App](https://amarsingh1014-langchain-learn-track-langgraphapp-fregmw.streamlit.app/)

## Contents

- **Jupyter Notebooks (97%)**  
  The bulk of this repository consists of Jupyter Notebooks. These notebooks walk through LangChain features, including agent creation, chaining, document loaders, and integrations. Each notebook is designed for hands-on exploration and learning.

- **Python Scripts (3%)**  
  Python files provide supporting code, utility functions, or backend logic for apps and notebooks.

- **Streamlit App**  
  The repository features an app built with Streamlit to demonstrate LangChain graph capabilities. You can access it via the link above.

## Notebooks & Apps Overview

- **Introductory Notebook:**  
  Get started with LangChain basics, setup, and environment preparation.
- **Agent & Chain Examples:**  
  Learn to build agents, chains, and workflows using LangChain.
- **Document Loader Demos:**  
  Explore how to load, process, and use documents for language applications.
- **App Integration:**  
  See examples of integrating LangChain logic with Streamlit for interactive demos.

*(For more details about each notebook and app, please refer to their individual descriptions within the repository.)*

## Getting Started

1. Clone the repository.
2. Install dependencies as noted in the notebooks or requirements files.
3. Launch Jupyter Lab to explore notebooks.
4. Try the Streamlit app for live demos.
